Modul 02

Konfigurasi Internet (ether3) & Routing Default

Modul ini membahas langkah-langkah penghubungan router ke internet melalui interface ether3, penentuan jalur Default Gateway, serta aktivasi aturan NAT Masquerade.

A. Landasan Teori

1. IP Address Interface WAN (ether3)

Pengalamatan IP pada interface penghubung ISP (`ether3`) berfungsi agar router MikroTik memiliki identitas yang sah di segmen jaringan lokal milik provider/internet.

2. Default Gateway (0.0.0.0/0)

Default route dengan alamat tujuan 0.0.0.0/0 mengarahkan seluruh lalu lintas data yang tujuannya tidak diketahui di tabel routing lokal menuju router milik ISP (Gateway ISP).

3. NAT (Network Address Translation) Masquerade

Aturan NAT dengan aksi *Masquerade* berfungsi menerjemahkan alamat IP lokal privat menjadi IP publik `ether3` ketika data dikirim ke luar jaringan, sehingga jaringan lokal dapat terhubung ke internet.

B. Langkah Kerja Konfigurasi

CATATAN PENTING: Ganti variabel xx pada seluruh IP Address dengan Nomor Absen Siswa. (Contoh: Absen 05 → 172.32.5.1/24)[cite: 11].
Langkah 5: Konfigurasi Internet (ether3) & Routing Default
  1. IP Address: Buka IP → Addresses → Klik +[cite: 11]. Isi Address: [IP_ISP]/[Prefix] | Interface: ether3 → OK[cite: 11].
  2. Gateway: Buka IP → Routes → Klik +[cite: 11]. Isi Dst. Address: 0.0.0.0/0 | Gateway: [IP_Gateway_ISP] → OK[cite: 11].
  3. NAT Masquerade: Buka IP → Firewall → NAT → Klik +[cite: 11].
    • Tab General: Chain: srcnat | Out. Interface: ether3[cite: 11].
    • Tab Action: Action: masquerade → OK[cite: 11].
